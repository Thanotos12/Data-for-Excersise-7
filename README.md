#  MPG Dashboard

An interactive data visualization dashboard built with **Panel**, **hvPlot**, and **scikit-learn**, designed to explore the classic **Auto MPG dataset** from the UCI Machine Learning Repository. This tool enables users to uncover trends, compare vehicle characteristics, and examine relationships between fuel efficiency and other features—all through a dynamic, user-friendly interface.

---

## 🔧 Installation Guide

To get started, make sure you have Python installed (preferably 3.8 or later), then install the required libraries:

```bash
pip install panel hvplot holoviews numpy pandas scikit-learn ucimlrepo
```

These packages enable:

- **Panel**: Building interactive dashboards with widgets and layout controls.
- **hvPlot**: High-level plotting API for Pandas and other data structures.
- **Holoviews**: Composable visualizations for complex data.
- **NumPy & Pandas**: Data manipulation and numerical operations.
- **Scikit-learn**: Regression modeling and preprocessing.
- **ucimlrepo**: Easy access to datasets from the UCI ML Repository.

---

## ▶️ How to Run

Once installed, launch the dashboard locally using:

```bash
panel serve dashboard.py --show
```

This will open the dashboard in your default web browser, allowing you to interact with the visualizations in real time.

## 📊 Dashboard Features

The dashboard is organized into three main analytical sections, each accessible via tabs:

### 🔹 Summary Panel
Provides a quick overview of the dataset:
- **Total number of cars**
- **Average MPG**
- **Maximum MPG**
- **Minimum MPG**

### 🔹 Question 1: Trend Over Time
Explore how key vehicle metrics evolve across model years:
- Select from **MPG**, **horsepower**, or **weight**
- Apply **smoothing** using a moving average slider
- Customize the **line color** for better visual clarity

This section helps identify historical shifts in vehicle design and fuel efficiency.

### 🔹 Question 2: MPG by Cylinder Count
Compare fuel efficiency across different engine configurations:
- Choose between **mean** or **median** MPG
- Customize the **bar color**
- Understand how cylinder count impacts fuel consumption

This is especially useful for evaluating trade-offs between engine power and efficiency.

### 🔹 Question 3: Weight vs MPG (Regression Analysis)
Investigate the relationship between vehicle weight and fuel efficiency:
- Interactive **scatter plot** with hover details
- Option to overlay a **regression line** (linear or polynomial)
- Customize **point size**, **opacity**, and **color**
- View **R² score** and **correlation coefficient** to assess model fit

This section offers a deeper statistical insight into how vehicle weight influences MPG, with the flexibility to toggle regression types for comparison.

## 📁 Data Source

The dashboard uses the **Auto MPG dataset** retrieved via the `ucimlrepo` package:

- Origin: UCI Machine Learning Repository
- Dataset ID: 9
- Features include: MPG, cylinders, displacement, horsepower, weight, acceleration, model year, and origin

This dataset is a staple in machine learning and data science education, ideal for regression tasks and exploratory data analysis.
